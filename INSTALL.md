# INSTALL.md — установка силами Claude Code (инструкция для агента)

Этот файл — инструкция для агента (Claude Code), которого пользователь попросил
установить этот набор на новую машину. Выполняйте шаги по порядку; всё, чего не
знаете, спрашивайте у пользователя, а не придумывайте.

## 0. Определите окружение

- ОС: Windows — PowerShell 5.1 есть из коробки; macOS/Linux — нужен pwsh 7
  (`brew install powershell` или установщик с сайта Microsoft).
- Проверьте `git --version` и `tar --version`. Чего-то нет — попросите
  пользователя поставить и остановитесь.
- `claude --version`: если CLI нет, но стоит расширение Claude Code для VS Code —
  это нормально (нативному бэкенду `claude` понадобится, предупредите, если его нет).

## 1. Соберите данные шлюза

Оркестратор работает и без шлюза (нативный бэкенд на подписке), поэтому сначала
уточните у пользователя, есть ли доступ к шлюзу hapy:

- **есть** — пусть вставит в чат адрес (`https://…`) и персональный токен
  (`hapy_…`). Они уйдут только в конфиги в домашнем каталоге пользователя;
  история сессии остаётся на этой машине. Токен не повторяйте в чате и не
  записывайте в файлы репозитория;
- **нет или пользователь не хочет пересылать токен через чат** — установите с
  `-NoToken` и подскажете пользователю запустить `.\install.ps1` (без параметров)
  самому в своём терминале: установщик спросит адрес и токен интерактивно.

Никогда не запускайте `install.ps1` без параметров сами: интерактивные запросы
(Read-Host) не сработают в неинтерактивном шелле агента. Либо оба параметра
(`-BaseUrl` и `-Token`), либо `-NoToken`.

## 2. Склонируйте и установите

Каталог клонирования спросите у пользователя (по умолчанию `~/ai-orchestrator`).

Windows, из каталога клона:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File install.ps1 -BaseUrl <адрес> -Token <токен>
```

macOS/Linux:

```sh
pwsh -NoProfile -File install.ps1 -BaseUrl <адрес> -Token <токен>
```

(вариант без шлюза — добавьте `-NoToken`). Повторный запуск безопасен: уже
настроенные файлы (без плейсхолдеров `__HAPY_*`) не перезаписываются.

## 3. Проверьте установку

Из каталога клона, в PowerShell/pwsh:

```powershell
& "$HOME/.claude/bin/claude-mode.ps1" status
```

Ожидаемый ответ на чистой машине: `current mode: hapy (gateway)`; если на машине
уже была настроена подписка — `claude (built-in)` (это нормально).

При настроенном шлюзе:

```powershell
& "$HOME/.claude/bin/hapy-ask.ps1" README.md
```

Ожидание: первая строка вида `digest: … (backend: gateway, …)` и короткая
выжимка файла. Если видите ошибку про плейсхолдеры `__HAPY_*` — адрес/токен не
подставились, вернитесь к шагу 2.

Нативный бэкенд (если пользователь на подписке Claude): нужен один вход
`claude` → `/login`, затем:

```powershell
& "$HOME/.claude/bin/glm-task.ps1" scout "перечисли файлы в корне репозитория" -Backend claude -MaxTurns 5
```

## 4. Расскажите пользователю, что дальше

- Команды появятся в **новом** терминале (PATH подхватывается только новыми
  сессиями): `hapy-ask`, `hapy-review`, `glm-task`, `claude-mode`.
- Основная сессия Claude Code не переключалась: чтобы вести и её через шлюз —
  `claude-mode hapy` + Reload Window (необязательно).
- Ничего не коммитьте в клон репозитория.
